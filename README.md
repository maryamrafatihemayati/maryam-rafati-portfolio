# پورتفولیو مریم رافتی حمایتی — طراح UX/UI

سایت شخصی و کیس‌استادی، ساخته‌شده با HTML، CSS و JavaScript ساده و منتشرشده روی GitHub Pages.

**آدرس زنده:** <https://maryamrafatihemayati.github.io/maryam-rafati-portfolio/>

---

## ساختار

```
index.html                      صفحهٔ اصلی (هیرو، نمونه‌کار، فرایند، درباره، مهارت‌ها، تماس)
case-studies/
  nill-pastry.html              کیس‌استادی کامل شیرینی‌پزی نیل — ۱۷ بخش
css/styles.css                  سیستم طراحی و تمام استایل‌ها
js/main.js                      ظهور تدریجی بخش‌ها، فهرست چسبان، سایهٔ هدر
assets/
  fonts/                        فونت استعداد (woff2، پنج وزن)
  images/nill/                  خروجی‌های Figma پروژهٔ نیل
  icons/favicon.svg
resume/                         رزومهٔ PDF و نسخهٔ HTML آن
```

## ویرایش محتوا

تمام متن‌ها مستقیم داخل فایل‌های HTML هستند و هیچ مرحلهٔ build ندارند.
کافی است فایل را ویرایش و ذخیره کنی.

برای دیدن تغییرات روی سیستم خودت، یکی از این دو:

```bash
python -m http.server 8000
# یا
npx serve .
```

بعد مرورگر را روی <http://localhost:8000> باز کن.

> باز کردن مستقیم فایل با `file://` هم کار می‌کند، اما سرور محلی رفتار واقعی‌تری دارد.

## تست‌ها

پیش از هر انتشار، این دستور را در پوشهٔ پروژه اجرا کن:

```bash
npm test
```

هیچ نصبی لازم نیست؛ فقط Node نسخهٔ ۲۰ به بالا. اگر همهٔ خطوط با ✔ تمام شد، سایت آمادهٔ انتشار است. اگر خطی با ✖ بود، نام تست به فارسی می‌گوید چه چیزی خراب شده.

تست‌ها در `tests/site.test.mjs` هستند و این موارد را بررسی می‌کنند:

| گروه | چه چیزی |
| --- | --- |
| ساختار | زبان و جهت فارسی، عنوان و متا، یک h1، توازن تگ‌ها، canonical و og:image |
| پیوندها | وجود همهٔ فایل‌های ارجاع‌شده، پیوندهای داخلی، فونت‌ها، رزومه، JSON-LD |
| کیس‌استادی | هم‌خوانی فهرست با بخش‌ها، عدد ۱۲۰ دقیقه، نقش‌های رنگی |
| تصاویر | alt، برابری ابعاد اعلام‌شده با فایل، جفت WebP و PNG، بودجهٔ حجم |
| نگارش فارسی | نبود خط تیرهٔ میان‌جمله، املای نادرست رایج، عبارات محاوره‌ای، ادعای پیاده‌سازی |
| تایپوگرافی | letter-spacing فقط روی لاتین و عدد، بارگذاری محلی فونت |
| تم | نبود هیچ اثری از تم تیره، احترام به «کاهش حرکت» |

اگر عمداً چیزی را عوض کردی که تستی را قرمز می‌کند (مثلاً عکس تازه با ابعاد متفاوت)، تست درست کار کرده است؛ ابعاد در HTML را هم به‌روز کن.

## انتشار

شاخهٔ `main` مستقیماً روی GitHub Pages منتشر می‌شود. هر push یعنی انتشار:

```bash
git add -A
git commit -m "توضیح تغییر"
git push
```

چند دقیقه بعد سایت به‌روز می‌شود.

## سیستم طراحی

رنگ‌ها به‌صورت توکن در `:root` تعریف شده‌اند.
برای تغییر رنگ اصلی، فقط `--accent` را در `css/styles.css` عوض کن.

| توکن | نقش |
| --- | --- |
| `--paper` | زمینهٔ صفحه |
| `--surface` | زمینهٔ کارت‌ها |
| `--ink` / `--ink-2` | متن اصلی و فرعی |
| `--accent` | رنگ تأکید (شرابی) |
| `--line` | خطوط و حاشیه‌ها |

## نکات نگهداری

- **عکس‌ها:** خروجی‌های Figma در `assets/images/nill/` هستند. هر عکس دو نسخه دارد: یک `.webp` که مرورگرها دانلود می‌کنند و یک `.png` به‌عنوان پشتیبان. در HTML با تگ `<picture>` کنار هم آمده‌اند؛ اگر عکسی را عوض کردی، هر دو نسخه را به‌روز کن.
- **ساخت نسخهٔ WebP:** با Pillow انجام می‌شود. برای عکس‌های شامل خط و متن از حالت بدون اتلاف (`lossless=True`) و برای عکاسی از `quality=95` تا `99` استفاده کن.
- **رزومه:** فایل `resume/Maryam-Rafati-UXUI-Resume.pdf` از هدر و دو جای دیگر لینک شده. اگر اسمش را عوض کردی، لینک‌ها را هم به‌روز کن.
- **افزودن پروژهٔ دوم:** یک کپی از `case-studies/nill-pastry.html` بگیر و در `index.html` بخش `#work` یک `article.work-card` دیگر اضافه کن.
